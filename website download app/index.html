Satu sistem yang menghubungkan seluruh pemangku kepentingan dalam pengelolaan sampah modern.

Dashboard Saldo & Poin

Pantau saldo poin dan total kilogram sampah yang berhasil Anda kumpulkan. Berikan kebanggaan dan transparansi hasil pilah sampah.

Drop-in Mandiri via Peta

Cari lokasi Drop Point terdekat di Google Maps untuk menyetor sampah sendiri tanpa harus menunggu jadwal armada keliling.

Penjemputan Sampah ke Rumah

Sampah menumpuk banyak atau berat? Cukup klik panggil kurir penjemput langsung ke alamat rumah Anda sesuai jadwal.

Tukar Poin Cuan & Voucher

Ubah poin yang didapat menjadi saldo tunai, uang digital, atau kupon diskon menarik. Sampah jadi berkah nyata!

Daftar Tugas Harian

Daftar penjemputan sampah harian rapi di layar smartphone tanpa perlu membawa kertas catatan yang rentan hilang atau rusak.

Status Perjalanan Realtime

Update status dari "Menuju Lokasi", "Sedang Menimbang", hingga "Selesai" agar nasabah dan admin bisa memantau progres lapangan.

Input Timbangan Aktual

Ketik angka timbangan asli di depan nasabah secara transparan. Saldo poin dihitung otomatis dan akurat.

Validasi Bukti Setor

Kirim bukti setoran sampah langsung ke server untuk diverifikasi cepat oleh Admin di kantor.

Kelola Akun & Hak Akses

Master Data Harga Sampah

Ekspor Laporan (PDF/Excel)

PANDUAN LENGKAP

Cara Mudah Memasang Aplikasi

Ikuti langkah mudah di bawah ini untuk memulai di perangkat pilihan Anda.

Panduan Install Android (APK)

  1. 1
    Download Berkas APK

    Klik tombol Download APK Android atau scan QR code dari HP Anda.

  2. 2
    Izinkan Instalasi dari Sumber Ini

    Jika muncul notifikasi keamanan browser (Chrome/Samsung Internet), pilih Pengaturan lalu aktifkan "Izinkan dari sumber ini" (Install unknown apps).

  3. 3
    Tekan Tombol Install

    Pilih "Tetap Install" jika muncul peringatan Google Play Protect. File 100% aman dan bebas virus.

  4. 4
    Buka dan Masuk ke Aplikasi

    Aplikasi siap digunakan! Masuk sebagai Nasabah atau Petugas Lapangan Anda.

Panduan Buka di Windows (PC)

  1. 1
    Download Paket Windows (.ZIP)

    Unduh file zip aplikasi bank sampah melalui tombol download Windows di atas.

  2. 2
    Ekstrak Berkas ZIP

    Klik kanan file zip yang telah didownload, lalu pilih "Extract All..." (Ekstrak Semua) ke folder pilihan Anda.

  3. 3
    Jalankan File Aplikasi

    Buka folder hasil ekstrak dan klik ganda pada file flutter_application_1.exe atau bank-sampah-windows.exe.

  4. 4
    Tips Praktis Shortcut Desktop

    Klik kanan file exe > Send to > Desktop (create shortcut) untuk akses cepat langsung dari desktop kantor.
